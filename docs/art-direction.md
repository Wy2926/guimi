# 美术设计规范

## 风格定位

**东方神话 · 通透灵韵**

以东方神话中的人物、神通、法宝与阵法构建视觉世界，采用具有立体材质感的风格化 3D 表现。整体气质清灵、凝练，兼具器物的分量与法力的轻盈。

通透感由清晰轮廓、虚实层次、结构间隙、细亮边缘和有方向的流动共同形成。角色、场景、技能与界面共享这套视觉语言，并通过各自的器形、材质、色彩和动势保持辨识度。

设计以约 60° 的正交俯视镜头和实际游玩尺寸为观察基准。

## 视觉原则

1. **实体有骨。** 主体轮廓明确，法宝有器形，人物有姿态，技能有核心或路径。关闭粒子与泛光后，造型依然成立。
2. **层间有空。** 内外结构通过厚度、半径、高度与倾角分离；环带、飘带和镂空之间保留可见空隙，让视线穿过外层抵达主体。
3. **灵光有层。** 实体面、能量结构和高光分别承担体积、动势与重点。高光集中在边缘、刻线、节点和接触瞬间。
4. **流动有向。** 聚拢、回旋、掠过、扩散等运动直接表达能力机制，光尘与云气沿这些路径组织。
5. **疏密有致。** 焦点处细节集中，外缘逐渐疏散；常态轻盈，关键动作短促强化，结束时干净收束。

## 造型与建模

### 神话意象

技能以「人物·神通／法宝／阵法」命名，依据所采用的神话人物与能力设计主体、纹样和动势。来源与游戏改编分别说明，文学设定与宗教教义保持清晰区分。

玉环、金石器、绫带、云纹、莲瓣和法印等元素按具体题材选用。装饰应参与造型或表达能力：纹路引导能量，器形决定轮廓，结构变化对应技能阶段。

### 形体结构

- 按“大轮廓 → 结构层次 → 局部纹样”的顺序设计，优先保证俯视辨识。
- 以舒展弧线、渐细飘带和纤细能量分叉组织轻盈部分；承重构件、器物主体与敌人躯干保留实体分量。
- 环带采用错层、断口与渐细收束；碎片和附属构件围绕主形分布，保持疏密节奏。
- 雕刻、镂空与材质分界集中在镜头可见部位；细节尺度以实际屏幕尺寸可读为准。
- 角色的头肩、手臂、武器与衣摆之间保留轮廓间隙，动作中仍能辨认朝向和重心。

### 材质表现

| 材质 | 表现重点 | 用途 |
| --- | --- | --- |
| 玉 | 细腻表面、柔和高光、清楚的厚薄变化 | 器物主体、嵌饰、阵法构件 |
| 金属与金石 | 凝练高光、边缘亮线、粗糙度对比 | 刃口、器物骨架、镶边、刻纹 |
| 石、木、布与骨 | 稳定中间调、柔和反射、清晰材质分区 | 场景、衣甲与生物躯体 |
| 灵光 | 细亮轮廓、局部流纹、随阶段变化的明度 | 能量带、法印、剑气与电弧 |
| 云气与光尘 | 薄层透明、渐隐边缘、稀疏分布 | 层间过渡、尾迹与空间氛围 |

实体保留必要的遮挡与体积；透明和加法混合用于云气、光尘及范围线等局部。通过实体与轻质层的对照形成通透感。

## 色彩与明度

单个资产以一种主色、一种辅助色和少量高光色组织。大面积环境保持低饱和、低对比，主体具有稳定中间调，能量结构适度提亮，接触瞬间形成短暂亮度峰值。

| 类别 | 色彩基准 | 视觉表达 |
| --- | --- | --- |
| 雷缚珠／暗 | 紫色 `#8835E5`、浅紫 `#CA8DFF`、黑色核心 | 内敛核心、薄亮边缘、回旋紫电与向内光尘 |
| 太极图／光 | 玉青 `#59DDCC`、淡金 `#F6D395` | 玉质阵心、金石纹路、清气环流与脉冲 |
| 火 | 暖橙、赤金、少量浅色火星 | 内部凝聚、外缘渐散、短促喷发 |
| 冰 | 清冷青蓝、少量霜白高光 | 凝练晶面、纤细棱线与碎霜 |
| 场景与器物 | 青灰、低饱和玉色、旧金及木布本色 | 冷暖局部点缀，突出材质与空间层次 |
| 界面 | 深青底、米白 `#EEE7D7`、金色 `#E4B76D`、青色 `#80D6CF` | 正文清晰，重点与状态有层次 |

元素色与能力语义一致。敌我、危险、选中和冷却等信息同时通过形状、明度、位置或文字表达。

## 粒子与技能动效

### 表现层次

每个效果按机制选择必要层次，各层承担明确的视觉职责。

| 层 | 职责 | 设计要求 |
| --- | --- | --- |
| 主体 | 建立器形、核心与遮挡 | 轮廓稳定，体积清楚 |
| 能量结构 | 呈现法力路径 | 细线、薄带、分叉与刻纹贴合主体，层间有空隙 |
| 细粒子 | 表达运动与速度 | 沿轨迹组织，焦点密、外缘疏，生命周期清楚 |
| 柔性介质 | 连接层次与空间 | 云气薄而轻，保留地面与主体可见度 |
| 范围与反馈 | 呈现作用区域和接触 | 边界清晰，接触短促提亮，装饰线从属于实际边界 |

向内旋转表达收束与牵引，沿路径拖尾表达速度，顺阵纹环流表达持续运转，向外散射表达冲击。粒子的方向、疏密、尺寸和消散共同支持这一动势。

### 动作节奏

- 出招建立方向与蓄势，接触形成短促重音，持续阶段维持低强度流动，结束时收束或疏散。
- 实体动作保持重心，能量层可用反向旋转或错速流动形成纵深。
- 技能成长通过主体数量、结构、覆盖范围或节奏变化体现；各阶段保留清楚的层间间隙。
- 动效与真实作用阶段同步，范围线对应实际作用区域；暂停时保持同一视觉时刻，结束后完整消散。

## 光照与场景

- 环境光建立可读的地面和角色中间调，主光呈现体积，局部轮廓光分离前后层。
- 泛光集中于能量外缘，亮线之间、器物之间保留明暗间隙。
- 技能光在作用位置形成短时重点，背景亮暗变化时主体轮廓保持清楚。
- 场景装饰集中于边缘、节点和远景焦点；战斗区域保持开阔，地面纹理服从预警与拾取物的可读性。
- 云气与环境粒子低密度分布，远近层次通过明度、饱和度和细节密度区分。
- 镜头保持稳定的战场观察关系，重要接触使用短促、受控的镜头重音。

## 各类资产设计

| 类别 | 造型与表现 | 识别重点 |
| --- | --- | --- |
| 玩家与角色 | 衣甲、器物和飘带分层，玉饰与法力局部提亮 | 身姿、朝向、武器与动作重心 |
| 敌人、精英与首领 | 体量、姿态和局部异象形成威胁层级，共享材质与能量语言 | 敌人类别、攻击前摇与作用方向 |
| 武器与法宝 | 器形凝练、虚实结合，能量沿刃口、刻纹或器物结构流动 | 神话意象、功能与攻击路径 |
| 场景与环境 | 石庭、器物与纹饰层次分明，装饰疏密有序 | 可行走区域、场地边界与空间焦点 |
| 图标与拾取物 | 提炼器形剪影，保留一个主视觉重点和局部灵光 | 技能、物品或拾取类别 |
| 菜单与宣传画 | 延续材质、轮廓和能量语言，用构图集中视觉重点 | 主体、主题与信息层级 |

## 界面与字体

界面以深青底、细边框、充足留白和局部灵光形成轻盈层次。信息底板保持稳定对比，法印与云纹集中于边角，正文区保持干净。

- 中文名称与说明使用 Noto Sans SC；数字与拉丁展示使用 Cinzel。
- 标题、正文、辅助信息通过字号、间距和明度区分，金色用于重点，青色用于状态。
- 选中和可交互状态由边框、明度及文字共同表达，过渡短促清楚。
- 图标优先保留器形与主色，小尺寸下轮廓和类别仍可辨认。
- 升级卡、暂停和结果界面保持统一的边距与信息顺序，适配长中文名称。

## 美术验收标准

- 神话意象、器形和能力动势相互对应。
- 正交俯视与实际游玩尺寸下，主体轮廓、朝向和结构层次清晰。
- 减弱泛光、隐藏粒子后，造型与材质分区仍然成立。
- 常态、接触和收束阶段均保留必要间隙，透明层遮挡与排序正确。
- 多技能同屏时，玩家、敌人、攻击预警、作用边界和拾取物可辨。
- 粒子沿机制方向运动，持续效果轻盈，接触重点鲜明，结束干净。
- 在 960×600、1280×720、1440×900 下，界面文字清楚，布局完整，长名称可读。
