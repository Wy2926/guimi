# 剑豪肉鸽：玩法与架构

用户已确认实施方向。当前是可调校的首版，不是生产完成版；这里的数值是首版起点，不宣称复刻 DNF 的原始数值表。

## 本期范围

2.5D 固定正交俯角跟随人物，小竞技场，自动近战，手动主动技能，定时刷怪，拾取经验，暂停三选一，一局胜负与重开。职业名「剑豪」。只保留一张空旷竞技场与现有占位模型。

竞技场半径 15.8；镜头偏移 `(10,24,10)`、正交 size 15，俯角约 59.5°。16:10 下竞技场约为屏幕可见地面面积的 1.9 倍，其他宽高比略有变化，不把长宽都扩大两倍。镜头平滑跟随人物，场边限制跟随中心，不随人物朝向旋转。

普通攻击只在可达距离出手、优先最近目标、不自动追怪。动作期间仍可移动，命中只短暂停动画，不冻结人物物理；裂环蓄势允许 65% 移速，按键可预约当前动作后的主动释放。群怪不互相充当移动平台或物理推挤墙，普通身体接触不扣血；接近态使用原生 NavigationAgent3D 避让，冲锋保持预警方向。

## 一局节奏

- 每 60 秒为一个节奏周期：前 20 秒集结，20–46 秒增压，最后 14 秒喘息；按时间推进，不等待清场。
- 追击怪有近战前摇，冲锋怪给出固定方向线预警，远程怪发射可躲弹丸。远程发射与首领扇形施放要求进入镜头视锥。
- 从四周场边交替生成，预警 0.8 秒，生成时再次保证离玩家至少 6 米；玩家靠近预警则重新选点并重新预警。
- 2、5、8 分钟精英；10 分钟停止普通生成并召唤最终首领。首领倒下胜利，玩家死亡失败；不实现复活或无尽。
- 常规存活上限 60、增压峰值 80，特殊敌人同样遵守峰值上限。首领不吃击退或硬直，精英减弱受控；玩家实际受伤后保护 0.65 秒。
- 经验掉落在地面保留，普通怪 6 点、冲锋/远程 8 点、精英 35 点，进入拾取范围后吸附。升级冻结战斗、刷怪、冷却和在途攻击；超额经验保留，连续升级逐次选卡。

## 技能与成长

| 技能 | 获得方式与类型 | Lv.1 调校值 |
| --- | --- | --- |
| 普通三连 | 初始普攻，物理 | 三段 100% / 112% / 152% 物攻 |
| 裂环斩 | 初始主动，物理 | 220% 物攻、3 秒冷却、半径 2.8 |
| 厉鬼 | 升级解锁主动 | 8 秒持续、24 秒冷却；近战伤害 ×1.5、攻速 ×1.25、近战范围 ×1.3 |
| 万剑归宗 | 升级解锁自动索敌被动，固定 | 单剑 20% 独立攻击；初始 2 把、每级加 1 把，最多 6 把；索敌半径 8.5 米，受范围属性加成 |
| 流星 | 独立解锁的被动，魔法、火 | 单次动作 28% 触发；128% 魔攻，0.9 秒预警，半径 3.2 |
| 雷缚珠 | 独立解锁的周期被动，魔法、光 | 每 4.5 秒一轮，每次命中 60% 魔攻；初始 1 颗、持续 4 秒，作用半径 0.85 |

技能上限 5 级。攻击技能每级加初始倍率的 20%；厉鬼每级增加 1 秒持续时间。厉鬼五式八击保留原各段权重，不把一次命中拆数字假装多段。飞剑、流星、雷缚珠命中不再抽取辅助触发概率。

万剑归宗直接复用 `assets/weapons/astral_edge/` 的光剑场景、自带拖尾与命中特效，不新建同类模型或特效。剑身缩放为原模型的 65%，长度由约 3.55 米缩为 2.31 米。待机时剑身平放、正面朝上，沿人物周身半径 1.65 米、高度 1.25 米的水平环缓慢旋转，与人物朝向和镜头解耦。每 0.24 秒检查可见且在范围内的敌人并调度空闲剑，完全不依赖普攻或挥剑事件。先曲线接近目标侧上方，随后中断原切线、立即转向目标身体，以 48 米/秒直线斜刺，刺入后停留 0.085 秒再接续下一次攻击；蓄势靠近阶段不结算伤害，突刺使用原生胶囊体覆盖前后两帧的剑身接触点，防止高速穿透漏判。每次真实命中独立触发沿刺入方向的白蓝爆闪和碎光，闪避不产生假命中特效，灯光、音效与镜头重音仍限频。无目标或目标离开范围后归位，返回位置始终跟随移动中的人物。升级只补足新剑，不替换或克隆飞行中的剑；每次突刺对同一敌人只结算一次。流星仍只由人物自身动作抽取触发概率。

雷缚珠不依赖普攻触发，只对可见且处于索敌范围内的敌人发射；无目标不空耗冷却。五级数量为 `1/1/2/2/3`，每级作用半径增加 0.15、球体尺寸增加初始值的 15%，作用半径再乘人物范围属性。冷却受冷却系数影响；已发射的球保留施放时尺寸与寿命，升级从下一轮生效。每颗球对同怪的伤害间隔为 0.35 秒，多球分别造成伤害，但共用该怪的控制间隔，避免连续叠加击退；普通怪短僵直后退，精英减控、首领免控。球按既定方向缓慢穿行，到期或离开竞技场后消失。

当前有两个主动与三个被动，尚未填满规划中的四个被动槽；不为暂不存在的技能实现装卸栏位系统。普攻和属性提升不占技能槽。

基础属性使用 `BattleStats` Resource，本局深拷贝。剑豪初始 120 生命，物攻/魔攻/独立攻击各 25，双防各 5，暴击 8%，暴伤总倍率 150%，移速 6.8（此前 5.4），拾取半径 2。无初始附魔、闪避或吸血。主角模型缩放由 1.3 降为 1.0，身体胶囊同步调整为半径 0.28、高度 1.27，脚下光圈同步缩小；普攻与技能攻击范围不随模型缩小。

经验需求为 `round(14 + 6×(等级−1) + 0.8×(等级−1)^1.5)`。三选一来自未满级技能、当前有效属性与四系附魔；至少保留一张可成长技能（如仍有）。三攻卡只在已有对应伤害类型的技能时出现，例如流星或雷缚珠解锁后才有魔攻卡。候选去重、排除满级；多级不被一次按键全部消费。

属性成长包含生命、三攻、双防、暴击、暴伤、移动、闪避、吸血、攻速、冷却、攻击范围、拾取。上限：暴击 75%、暴伤总倍率 300%、闪避 40%、吸血 12%、攻速 ×2、范围 ×1.8、冷却时长系数最低 0.4。生命上限升级补充新增的生命值，不每次升级回满。完整步长在 `run_progression.gd` 单点调整。

## 伤害口径

四属性是火、冰、光、暗攻击，不是力量/智力/体力/精神。此前“真伤”已更正为固定伤害。

| 类型 | 基础伤害 | 防御 | 后续修正 |
| --- | --- | --- | --- |
| 物理 | 物攻 × 技能倍率 | 物防 | 元素，然后暴击时应用暴伤 |
| 魔法 | 魔攻 × 技能倍率 | 魔防 | 元素，然后暴击时应用暴伤 |
| 固定 | 独立攻击 × 技能倍率 | 跳过双防 | 元素，然后暴击时应用暴伤 |

固定不是恒定数字，也不自动无视闪避或无敌；三种技能只读取各自基础攻击力。“百分比”是具体技能的攻击倍率，不另造含义不明的通用百分比面板项。

首版公式：

1. 接收者先受闪避概率约束；伤害计算读取技能指定攻击力与倍率。
2. 物理/魔法乘 `100 / (100 + max(对应防御, 0))`，固定跳过此步。
3. 有元素时乘 `clamp(1 + 该元素强化 − 目标该元素抗性, 0.15, 3)`。
4. 暴击成立后乘暴伤总倍率，未暴击不乘；最后四舍五入，有效命中最低 1 点。
5. 接收者检查无敌/死亡，扣除不超过剩余生命的实际伤害，发出一次死亡事件。

每次命中只使用一个元素：技能显式元素优先（流星固定火、雷缚珠固定光），否则继承人物附魔；无属性跳过元素修正。附魔选卡只替换继承元素，不覆盖技能自带属性；已有各元素强化保留但不同时叠乘。普通元素怪本系抗性 35%，对立弱点 −20%；火冰对立，光暗对立。

伤害结果包含伤害值、实际扣血、暴击、闪避、免疫、击杀。吸血按实际扣血计算，不计过量伤害；恢复预算最多存储 12% 最大生命，以每秒 12% 最大生命补充，防止群攻瞬间无限回血。伤害数字、击杀与经验不各算一套伤害。

本期不实现草系反应标签、灼烧、爆炸、反应链；高抗/弱点是基础元素增减伤，不是元素反应的替代实现。

## 代码边界与后续接入

| 职责 | 当前边界 |
| --- | --- |
| 本局组装与生命周期 | `arena.gd` 连接玩家、成长、刷怪、技能、HUD；唯一拥有暂停、胜负与重开 |
| 玩家与敌人 | 分别使用 CharacterBody3D 场景，互不继承木桩复活逻辑 |
| 属性与技能定义 | 原生 Resource / `.tres`；当前成长状态不回写共享配置 |
| 伤害数学 | `DamageRules.calculate` 只接受必要战斗属性，不识别职业菜单、背包、宠物或 UI |
| 技能执行 | 显式注入玩家、成长与表现；复用 AnimationPlayer 事件、Area3D、原生路径与补间 |
| 敌人和刷怪 | 敌人只知道目标和战斗属性；WaveDirector 负责节奏与数量，不负责经验和升级 |
| 经验与三选一 | RunProgression 只管理本局构筑；HUD 发选择信号，不自行修改属性或暂停 |
| 表现 | Feedback 播放效果；群体命中的主震屏、重音限频，伤害数字最多 40 个；怪物闪白材质只在受击时绘制 |

未来职业提供基础属性、初始技能和成长池，当前对应 RunProgression 的 `base_stats`、`initial_skills`、`skill_definitions` 输入。装备、特殊物品可在进入对局时组合这些输入；局内技能不读取它们的存档、库存、稀有度或界面。

未来宠物作为独立单位可共用同一个伤害计算与目标接收入口，再按真实需求接奖励归属；当前不创建空宠物、装备、存档、词条或职业管理器。新行为仍需代码，不承诺任意玩法零修改。

不自建 ECS、全局 EventBus、DI、技能图、公式解释器、动画、物理、导航或对象池。空旷场地直接追逐，群体间距用引擎原生避让，不查询路径；真正有障碍需求再加原生导航网格。只有测量证明需要时才加优化。

## 验收边界

自动化覆盖伤害分源、固定绕双防与元素暴击、真实敌人攻击、拾取、连续选卡、暂停、重开、首领单次生成、飞剑实例与大于 16 目标的范围伤害。技能迭代继续验证现成剑和特效复用、水平环绕、无普攻自动索敌、范围边界、2→6 剑增长、移动归位、暂停与重开，以及主角缩小后的碰撞和提高后的实测移速、雷珠固定光属性与周期控制。HUD 的三种窗口尺寸与可见画面检查不计入 headless 验收。

`scripts/run.ps1 -Verify` 强制附带 `--headless`，测试不弹出游戏窗口；headless 用于逻辑，不用于画面、渲染性能或音频验收。此前的本机短时渲染压力报告不能代表本次改动、最低硬件、完整十分钟的主观平衡性、实体手柄或生产平台质量。当前默认 PC，最低硬件和更大负载目标仍需按实际测试确定。
