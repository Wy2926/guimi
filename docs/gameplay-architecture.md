# 剑豪肉鸽：玩法与架构

用户已确认实施方向。当前是可调校的首版，不是生产完成版；这里的数值是首版起点，不宣称复刻 DNF 的原始数值表。

角色、场景、技能与界面的造型、材质、配色、粒子和光照标准见 [美术设计规范](art-direction.md)。

## 本期范围

2.5D 固定正交俯角跟随人物，小竞技场，自动近战，手动主动技能，定时刷怪，拾取经验，暂停三选一，一局胜负与重开。职业名「剑豪」。只保留一张空旷竞技场与现有占位模型。

竞技场半径 15.8；镜头偏移 `(10,24,10)`、正交 size 15，俯角约 59.5°。16:10 下竞技场约为屏幕可见地面面积的 1.9 倍，其他宽高比略有变化，不把长宽都扩大两倍。镜头平滑跟随人物，场边限制跟随中心，不随人物朝向旋转。

普通攻击只在可达距离出手、优先最近目标、不自动追怪。动作期间仍可移动，命中只短暂停动画，不冻结人物物理；裂环蓄势允许 65% 移速，按键可预约当前动作后的主动释放。群怪不互相充当移动平台或物理推挤墙，普通身体接触不扣血；接近态使用原生 NavigationAgent3D 避让，冲锋保持预警方向。

## 一局节奏

- 每 60 秒为一个节奏周期：前 20 秒集结，20–46 秒增压，最后 14 秒喘息；按时间推进，不等待清场。
- 追击怪有近战前摇，冲锋怪给出固定方向线预警，远程怪发射可躲弹丸。远程发射与首领扇形施放要求进入镜头视锥。
- 从四周场边交替生成，预警 0.8 秒，生成时再次保证离玩家至少 6 米；玩家靠近预警则重新选点并重新预警。
- 2、5、8 分钟精英；10 分钟停止普通生成并召唤最终首领。首领倒下胜利，玩家死亡失败；不实现复活或无尽。
- 常规存活上限 60、增压峰值 80，特殊敌人同样遵守峰值上限。首领不吃击退或硬直，精英减弱受控；玩家实际受伤后保护 0.65 秒。
- 经验掉落在地面保留，普通怪 6 点、冲锋/远程 8 点、精英 35 点，进入拾取范围后吸附。升级冻结战斗、刷怪、冷却和在途攻击；超额经验保留，连续升级逐次选卡。

## 技能与成长

技能创作统一遵循 [东方神话原则](../README.md#技能创作原则)：从人物的神通、法宝或阵法推导肉鸽机制。阐教、截教、道家、佛教等人物均可作为来源，归属以采用的具体故事版本为准，不另造门派框架。下面保留尚未迭代的原型名。

| 技能 | 获得方式与类型 | Lv.1 调校值 |
| --- | --- | --- |
| 普通三连 | 初始普攻，物理 | 三段 100% / 112% / 152% 物攻 |
| 裂环斩 | 初始主动，物理 | 220% 物攻、3 秒冷却、半径 2.8 |
| 厉鬼 | 升级解锁主动 | 8 秒持续、24 秒冷却；近战伤害 ×1.5、攻速 ×1.25、近战范围 ×1.3 |
| 万剑归宗 | 升级解锁自动索敌被动，固定 | 单剑 20% 独立攻击；初始 2 把、每级加 1 把，最多 6 把；索敌半径 8.5 米，受范围属性加成 |
| 罗宣·照天印 | 独立解锁的被动，魔法、火 | 单次动作 28% 触发；128% 魔攻，0.9 秒悬印预警，半径 3.2；落地原体崩裂 |
| 雷缚珠 | 独立解锁的周期被动，魔法、暗 | 每 4.5 秒一轮，每次命中 60% 魔攻；初始 1 颗，碰敌展开半径 2.6 的黑洞，停驻 4 秒 |
| 太上老君·太极图 | 升级解锁的随身阵法被动，魔法、光 | 每 1.2 秒对阵内敌人结算 55% 魔攻，半径 2.6；无需普攻 |
| 哪吒·混天绫 | 升级解锁的连锁被动，魔法、无属性 | 单次 88% 魔攻，最多 3 名不同目标；初始索敌 8.5 米、单跳 4.6 米，冷却 4.2 秒；无需普攻 |

技能上限 5 级。攻击技能每级加初始倍率的 20%；厉鬼每级增加 1 秒持续时间。厉鬼五式八击保留原各段权重，不把一次命中拆数字假装多段。飞剑、照天印、雷缚珠命中不再抽取辅助触发概率。

万剑归宗直接复用 `assets/weapons/astral_edge/` 的光剑场景、自带拖尾与命中特效，不新建同类模型或特效。剑身缩放为原模型的 65%，长度由约 3.55 米缩为 2.31 米。待机时剑身平放、正面朝上，沿人物周身半径 1.65 米、高度 1.25 米的水平环缓慢旋转，与人物朝向和镜头解耦。每 0.24 秒检查可见且在范围内的敌人并调度空闲剑，完全不依赖普攻或挥剑事件。先曲线接近目标侧上方，随后中断原切线、立即转向目标身体，以 48 米/秒直线斜刺，刺入后停留 0.085 秒再接续下一次攻击；蓄势靠近阶段不结算伤害，突刺使用原生胶囊体覆盖前后两帧的剑身接触点，防止高速穿透漏判。每次真实命中独立触发沿刺入方向的白蓝爆闪和碎光，闪避不产生假命中特效，灯光、音效与镜头重音仍限频。无目标或目标离开范围后归位，返回位置始终跟随移动中的人物。升级只补足新剑，不替换或克隆飞行中的剑；每次突刺对同一敌人只结算一次。照天印仍只由人物自身动作抽取触发概率。

雷缚珠不依赖普攻触发，只对可见且处于索敌范围内的敌人发射；无目标不空耗冷却。五级数量为 `1/1/2/2/3`，黑洞半径为 `2.6/2.95/3.3/3.65/4.0`，球体每级增大初始值的 15%，两者均受范围属性影响。冷却受冷却系数影响；已发射的球保留施放时尺寸和持续时间，升级从下一轮生效。

紧凑紫电球以 2.8 米/秒直行，飞行最多 4 秒。首次碰到活敌人即停在接触位置，以 0.42 秒补间展开原生 Area3D，停驻 4 秒后用 0.32 秒收缩消散；未碰敌不生成黑洞，越出竞技场提前消散。每颗球对同怪每 0.35 秒结算一次暗属性魔法伤害，不再击退或硬直。普通怪减速 55%，向中心牵引速度上限 3.8 米/秒；越靠近中心吸力越强，中心留有缓冲，移动仍走敌人的 `move_and_slide`。多黑洞伤害独立，减速不叠加、合成牵引限速；精英仅受 35% 控制强度，首领免减速和拉扯但正常受伤。离开范围、消散、死亡或重开时释放控制来源，不修改敌人基础属性。

资源位于 `assets/effects/thunder_orb/`：先生成概念图，再用 Blender 制作黑色核心、分层吸积带、三组分叉紫电和碎片，保留 `.blend` 并导出含原生旋转动画的 `.glb`。运行时复用现有光剑能量着色器、范围环、拖尾和爆发粒子；增加不透明黑洞核心的边缘发光材质。飞行拖尾、向内旋转碎光、雾状粒子及接触爆发分层呈现，局部动画与着色器时钟随暂停冻结。制作脚本为 `tools/build_thunder_orb.py`。

当前有两个主动与五个被动；沿用现有成长池与 HUD，不增加装卸栏位系统。普攻和属性提升不占技能槽。

### 罗宣·照天印

来源为[《封神演义》第六十四回](https://zh.wikisource.org/zh-hans/封神演義/卷064)罗宣祭照天印击龙吉公主的情节。朱砂玉石印台、镂空火焰印纽、镇落范围火伤与投影碎裂均为游戏改编，不声称原著法宝本体会自毁，也不将小说设定等同宗教教义。

- 先用内置 imagegen 生成[实例参考图](../assets/effects/zhaotian_seal/concept/zhaotian-seal.png)，再据图完成 Blender 模型：阶梯印台、鎏金包角、侧面云纹与离卦、三瓣弯曲火焰印纽、内焰和烘焙朱砂纹理。复用光剑 `AE_Gold` 材质；12 块玉石与 3 块印纽共 15 个独立网格、57 个材质表面、28,128 三角面，纹理嵌入 GLB 与源文件（Godot 导入时提取纹理）。这些是资产统计，不是实际 GPU draw call 或性能承诺。
- 预警共 0.9 秒：悬空蓄势 0.22 秒，随后加速镇落；由原 `SwordStorm` 在物理接触帧对范围内每怪结算一次火属性魔法伤害。半径为 `3.2 × 范围系数`，预警外沿与真实边界一致，不因敌人碰撞体擦边而越界伤害；沿用重击硬直，并以落点为中心向外击退。碎块不带碰撞与二次伤害，不触发其它被动。
- `SealShatter` 是 Blender 导出的 1.2 秒原生动画：顿压、裂开、向外弹起翻滚、回落轻弹、缩小化烬。飞行时就是这些分块组成完整印体，落地不留下隐形或重复的完整模型。粒子复用 `Feedback`：飞行金星 32、朱焰拖丝 24、薄焰 12；接触火星 48、上升余烬 26、非发光薄尘 14，共 156 槽。另复用能量／薄焰着色器、双层冲击环、接触灯光、三层音效与原命中镜头重音。
- 下落、碎裂、着色器时钟、发射器与伤害随暂停冻结；终止、死亡、胜利和重开由原节点所有者清理，已落地的碎块也能取消。保留内部 `meteor` ID 以复用现有成长、触发和统计；旧 `data/skills/meteor.tres`、临时球体造型和旧专属特效入口已移除，没有保留平行旧版资源。
- [Blender 源文件](../assets/effects/zhaotian_seal/source/zhaotian_seal.blend)、[GLB](../assets/effects/zhaotian_seal/zhaotian_seal.glb)、[完整生图提示词](../assets/effects/zhaotian_seal/concept/prompt.txt)。制作脚本 `tools/build_zhaotian_seal.py`；模型及碎裂参考渲染写入 `artifacts/zhaotian-seal-*.png`，不冒充游戏内 GPU 粒子实拍。

### 太上老君·太极图

以太极图“两仪变化”的神话意象创作随身阵法；周期清气、光属性及数值均为本游戏改编，并非原典法术规则（故事参照：[《封神演义》第六十一回](https://zh.wikisource.org/zh-hans/封神演義/卷061)）。

- 五级倍率为 `55/66/77/88/99%` 魔攻，半径为 `2.6/2.85/3.1/3.35/3.6` 米，受攻击范围加成；周期受冷却系数影响。光属性不被附魔覆盖，不附带击退、硬直或辅助技能递归触发，暴击、抗性、吸血统一走现有伤害入口。
- 阵心跟随人物位置、不随朝向旋转，使用原生 `Area3D` 圆柱重叠并复核敌人中心处于可见半径内；每轮每怪一次，不因体积擦边而超界伤害。解锁后持续存在，升级原位扩圈、不复制阵法或刷新免费脉冲；暂停冻结，死亡、胜利和重开释放实例。
- 模型包含玉质阴阳鱼、鱼鳞浮雕、鎏金 S 线、八组不同的三爻卦象、云纹和镂空刻度环；三个枢轴使用原生反向旋转动画。复用光剑金属材质、能量着色器、范围环和 `Feedback.attach_trail`，四层粒子为青色环流（64）、金色灵尘（32）、浮升符片（16）、清气脉冲（48），最多 160 个粒子槽，发射器只创建一次。
- 资源：[实例概念图](../assets/effects/taiji_aura/concept/taiji-aura.png)、[实际模型渲染](../assets/effects/taiji_aura/concept/taiji-aura-model.png)、[Blender 源文件](../assets/effects/taiji_aura/source/taiji_aura.blend)、[GLB](../assets/effects/taiji_aura/taiji_aura.glb)。建模脚本 `tools/build_taiji_aura.py`，图像使用内置 imagegen，完整提示词保存在同目录 `concept/prompt.txt`；模型渲染不冒充游戏内粒子实拍。

基础属性使用 `BattleStats` Resource，本局深拷贝。剑豪初始 120 生命，物攻/魔攻/独立攻击各 25，双防各 5，暴击 8%，暴伤总倍率 150%，移速 6.8（此前 5.4），拾取半径 2。无初始附魔、闪避或吸血。主角模型缩放由 1.3 降为 1.0，身体胶囊同步调整为半径 0.28、高度 1.27，脚下光圈同步缩小；普攻与技能攻击范围不随模型缩小。

经验需求为 `round(14 + 6×(等级−1) + 0.8×(等级−1)^1.5)`。三选一来自未满级技能、当前有效属性与四系附魔；至少保留一张可成长技能（如仍有）。三攻卡只在已有对应伤害类型的技能时出现，例如照天印或雷缚珠解锁后才有魔攻卡。候选去重、排除满级；多级不被一次按键全部消费。

属性成长包含生命、三攻、双防、暴击、暴伤、移动、闪避、吸血、攻速、冷却、攻击范围、拾取。上限：暴击 75%、暴伤总倍率 300%、闪避 40%、吸血 12%、攻速 ×2、范围 ×1.8、冷却时长系数最低 0.4。生命上限升级补充新增的生命值，不每次升级回满。完整步长在 `run_progression.gd` 单点调整。

### 哪吒·混天绫

采用[《封神演义》第十二回](https://zh.wikisource.org/zh-hans/封神演義/卷012)中哪吒红绫搅动江水、展开裹敌的文学意象。曲线连锁、缠身抽击、朱绫金边云纹、无属性魔法和下面的数值属于游戏改编；不把小说法宝等同宗教教义，也不因绫身朱红就强加火伤或灼烧。

- 从原成长池独立领悟，不依赖普攻、不解锁飞剑。同一条绫带每轮最多依次攻击 `3/4/5/6/7` 个不同敌人，单次倍率 `88/105.6/123.2/140.8/158.4%` 魔攻；单轮不回跳刷同一目标，闪避也消耗该目标的一次访问。无目标不消耗冷却。
- 初始从人物周围 8.5 米内的可见敌人选最近者，后续从当前敌人位置选 4.6 米内最近的未访问目标，并始终受人物索敌距离与镜头视锥约束；贴身回旋不能偷偷扩大敌人之间的跳距。两种距离均受范围属性影响；锁定后的敌人离场、死亡、隐藏或被释放会取消未结算接触并安全转接／归位。冷却为 `4.2 × 冷却系数` 秒，从祭绫起计；全场同时至多一条绫带，上一轮收尾结束前不会复制下一条。
- 运行时直接扩展现有 `SwordStorm`：复用目标集合、`Path3D/PathFollow3D/Curve3D`、物理时钟补间和胶囊接触查询。头部切向接近敌人后，以 0.56 米半径在 0.30 秒内真实绕行 240°，约 0.12 秒时查询头部实际接触；不会停在原地让整条模型切换成圆圈。下一段沿用当前切线。伤害仍走 `DuelFighter.deal_damage`，复用魔防、暴击、闪避、吸血、敌人 `Hit_A`／硬直与击退、击杀经验和首领胜利，不递归触发其它被动；首领控制免疫不变。
- 12 米实体绫身采用“头走过哪里，后段随后经过哪里”的弧长跟随：只记录头部原生曲线的世界空间轨迹，65 个蒙皮段依照各自距头部的固定距离采样。历史按长度保留，最多 384 点，不按时间过期；头转向、停止或换目标不重置尾巴。主模型不继承头部根节点的移动／旋转，不做整体拉伸、整条形态混合或复制绫圈。相邻敌人间的连接与缠绕由同一张布面真实形成，尾部和粒子不额外伤人。
- 等级、伤害倍率、跳数与范围在祭出时快照；升级不替换在途绫带、不刷新免费攻击。归位终点追踪人物，剩余绫身继续沿原轨迹逐段收入头部，然后渐隐释放；不是整条缩放到一点。暂停冻结头部、骨骼、轨迹、接触计时、着色器时钟与冷却；死亡、停用辅助攻击、胜利、重开复用原执行器清理入口。动态包围盒覆盖实际弯曲后的绫身，防止转弯时尾部被裁掉。
- 保留先前生成的[实例参考图](../assets/effects/huntian_ling/concept/huntian-ling.png)与[提示词](../assets/effects/huntian_ling/concept/prompt.txt)，复用连续双面绫身、燕尾端、褶皱、双金边、六组立体云纹和 UV 丝织材质，`AE_Gold` 沿用光剑材质。Blender 将同一网格改为原生骨骼蒙皮：1 网格、3 材质表面、21,516 三角面、65 个变形骨骼加 1 个静止根骨骼，各顶点最多两骨骼混合。各段是根骨骼的独立子骨，不通过头骨带动整个父子链；运行时用 [Skeleton3D 原生姿态接口](https://docs.godotengine.org/en/stable/classes/class_skeleton3d.html)驱动。删除旧整条 morph 动画和额外光带／绫圈替身，实体轮廓本身表达运动。这些是资源统计，不是 GPU 性能承诺。

## 伤害口径

四属性是火、冰、光、暗攻击，不是力量/智力/体力/精神。此前“真伤”已更正为固定伤害。

| 类型 | 基础伤害 | 防御 | 后续修正 |
| --- | --- | --- | --- |
| 物理 | 物攻 × 技能倍率 | 物防 | 元素，然后暴击时应用暴伤 |
| 魔法 | 魔攻 × 技能倍率 | 魔防 | 元素，然后暴击时应用暴伤 |
| 固定 | 独立攻击 × 技能倍率 | 跳过双防 | 元素，然后暴击时应用暴伤 |

固定不是恒定数字，也不自动无视闪避或无敌；三种技能只读取各自基础攻击力。“百分比”是具体技能的攻击倍率，不另造含义不明的通用百分比面板项。

首版公式：

1. 接收者先受闪避概率约束；伤害计算读取技能指定攻击力与倍率。
2. 物理/魔法乘 `100 / (100 + max(对应防御, 0))`，固定跳过此步。
3. 有元素时乘 `clamp(1 + 该元素强化 − 目标该元素抗性, 0.15, 3)`。
4. 暴击成立后乘暴伤总倍率，未暴击不乘；最后四舍五入，有效命中最低 1 点。
5. 接收者检查无敌/死亡，扣除不超过剩余生命的实际伤害，发出一次死亡事件。

每次命中只使用一个元素：技能显式元素优先（照天印固定火、雷缚珠固定暗、太极图固定光），否则继承人物附魔；无属性跳过元素修正。附魔选卡只替换继承元素，不覆盖技能自带属性；已有各元素强化保留但不同时叠乘。普通元素怪本系抗性 35%，对立弱点 −20%；火冰对立，光暗对立。

伤害结果包含伤害值、实际扣血、暴击、闪避、免疫、击杀。吸血按实际扣血计算，不计过量伤害；恢复预算最多存储 12% 最大生命，以每秒 12% 最大生命补充，防止群攻瞬间无限回血。伤害数字、击杀与经验不各算一套伤害。

本期不实现草系反应标签、灼烧、爆炸、反应链；高抗/弱点是基础元素增减伤，不是元素反应的替代实现。

## 代码边界与后续接入

| 职责 | 当前边界 |
| --- | --- |
| 本局组装与生命周期 | `arena.gd` 连接玩家、成长、刷怪、技能、HUD；唯一拥有暂停、胜负与重开 |
| 玩家与敌人 | 分别使用 CharacterBody3D 场景，互不继承木桩复活逻辑 |
| 属性与技能定义 | 原生 Resource / `.tres`；当前成长状态不回写共享配置 |
| 伤害数学 | `DamageRules.calculate` 只接受必要战斗属性，不识别职业菜单、背包、宠物或 UI |
| 技能执行 | 显式注入玩家、成长与表现；复用 AnimationPlayer 事件、Area3D、原生路径与补间 |
| 敌人和刷怪 | 敌人只知道目标和战斗属性；WaveDirector 负责节奏与数量，不负责经验和升级 |
| 经验与三选一 | RunProgression 只管理本局构筑；HUD 发选择信号，不自行修改属性或暂停 |
| 表现 | Feedback 播放效果；群体命中的主震屏、重音限频，伤害数字最多 40 个；怪物闪白材质只在受击时绘制 |

未来职业提供基础属性、初始技能和成长池，当前对应 RunProgression 的 `base_stats`、`initial_skills`、`skill_definitions` 输入。装备、特殊物品可在进入对局时组合这些输入；局内技能不读取它们的存档、库存、稀有度或界面。

未来宠物作为独立单位可共用同一个伤害计算与目标接收入口，再按真实需求接奖励归属；当前不创建空宠物、装备、存档、词条或职业管理器。新行为仍需代码，不承诺任意玩法零修改。

不自建 ECS、全局 EventBus、DI、技能图、公式解释器、动画、物理、导航或对象池。空旷场地直接追逐，群体间距用引擎原生避让，不查询路径；真正有障碍需求再加原生导航网格。只有测量证明需要时才加优化。

## 验收边界

太极图沿用 `tools/verify.gd` 验证升级卡接入、光属性伤害、范围边界、32 目标完整命中、粒子节点预算与复用、模型原生动画、移动跟随、暂停、死亡、阵法击杀首领和重开；满技能负载包含五级阵法。这些无窗口检查不证明 GPU 粒子画面或渲染帧率。
