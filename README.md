# 烬庭 · Ember Yard

Godot 动作试验场。一名骑士、同一块地面和复用同一模型的四名骸骨守卫，逐步打磨普通连段、「厉鬼」状态、裂环斩与「万剑归宗」的动作和反馈；不扩地图、怪物种类或装备系统。

双击 `Play.cmd`，或用 Godot 导入 `project.godot` 后按 F5。本机使用 Godot 4.7.2 / Forward+；首次进入会预热特效。其他机器可运行 `./scripts/run.ps1 -Godot 'C:\Tools\Godot.exe'`。

| 操作 | 键鼠 | 手柄映射 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 普通连段（可按住连续衔接） | J / 左键 | X |
| 裂环斩 | K / 右键 | RB |
| 厉鬼状态开关 | G | B |
| 万剑归宗开关 | L | Y |
| 重置 | R | 暂停菜单 |
| 暂停 / 设置 | Esc | Start |
| 全屏 | F11 | — |

暂停菜单提供 **60 FPS / 120 FPS** 两档，默认 120 FPS，选择会保存；实际帧率取决于硬件。物理与动画事件保持 120 Hz，两档使用相同战斗时序。可以关闭镜头震动与推近、开启静音。守卫只移动、受击、倒下和重生，方便反复调招。

## 本轮：普通连段与厉鬼状态

- 常态为三式三击：连续衔接三种现有成品骨骼动作，不再循环同一次挥刀。长按 J / 左键 / X 循环连段，短按也可逐式衔接；停手后回到起手式。
- G / 手柄 B 开关「厉鬼」：普攻变为五式八击，各式分别有 2 / 1 / 1 / 3 / 1 个独立攻击窗口。多段是实际伤害判定，不是把一次伤害拆成多个数字。
- 厉鬼各段按自己的基础伤害乘 1.5，攻速提高 25%、攻击范围增加约 30%。完整全中伤害由常态 91 提升至厉鬼 270（不含飞剑和流星）；高频段单独调低基础值，并非每段伤害都高于常态单击。
- 动作中切换会先完成当前招式再生效，HUD 提示待切换状态；不增加怒气、冷却、技能树等本轮不需要的系统。当前式数、段序和动作进度显示在原攻击区域。
- 刀光使用现有素材与 Godot 原生粒子、网格、材质和补间，动作继续复用 KayKit 成品动画，由 `AnimationPlayer` 事件同步出手、攻击窗口与反馈。

## 万剑归宗与流星

- 默认进入御剑状态：复用 Niko 的原作 Katana 模型，八把无鞘长剑悬浮于身后，保留原作造型与材质并配合粒子；按 L 随时切回纯近战。这里的“出鞘”指离开剑阵出击，不增加剑鞘模型。
- 每次真正挥剑带出连续剑阵，按住普攻可持续出剑；在 8.5 米内轮转分配多个敌人，不只追击一个目标。
- 每波最多三把背后的剑实际离位，原位置随即空出；同一个模型实例沿 Godot 原生 `Curve3D / Path3D / PathFollow3D` 弯曲穿插、攻击后循曲线回到原位置。全程只有这八把剑，归位后可再次出击，不在身后留复制品或额外生成飞剑。
- 沿途伤害使用原生物理查询；同一次出击对同一敌人只结算一次。持续输出来自这八把剑反复出击与返回，同时在途不会超过八把。
- 每个玩家攻击动作有 28% 概率引来一颗流星，多段动作只抽取一次：地面预警后 0.9 秒落下，在 3.2 米范围结算 32 伤害；飞剑和流星命中不会递归触发更多流星。
- 暂停同时冻结飞行与落星倒计时；关闭状态、重置或人物死亡会清理在途攻击。辅助命中沿用现有受击、音效和伤害数字，不为每把飞剑冻结玩家动作。

四名守卫用于直接看清多目标分配、曲线穿插和范围命中，均复用原角色、动画与重生逻辑。只增加这一项专用技能脚本，未引入通用技能、弹幕或对象池框架。

## 裂环斩

以下为常态数据；厉鬼下同样应用伤害、攻速和范围加成，3 秒冷却不变。

- 0–340 ms：原有回旋动画蓄势，青蓝能量环收束，剑身聚光。
- 340 ms：全身回旋，双层刀弧扫出，低沉破风声同步启动。
- 440–520 ms：2.8 米半径的原生 Area3D 判定；每个目标每次施放最多结算一次 55 伤害，同时释放扩散刀环与碎光。
- 命中：85 ms 双方局部顿帧、强击退、青白接触闪光、重击音、短震和伤害数字；击杀顿帧 105 ms。空放不触发命中反馈。
- 780 ms 起允许低速移动；1040 ms 动作结束（不计顿帧）。冷却 3 秒；冷却期间普攻照常可用，动作末段支持单槽衔接。

裂环斩保留独立按键与冷却，普通连段无需等待技能冷却，万剑追击与概率落星也保持可用。

## 当前人物外观

骑士换上同一 KayKit 包内的游侠战袍、护腕、靴子与披风，保留原头部、头盔和骨骼。武器改为包内现成的宽刃双手剑，仍用原右手挂点；技能聚光跟随新剑。只替换实际模型，不新增装备栏、换装系统或动画重定向。

原始普攻与裂环斩版本保存在 Git 标签 `v0.1-combat`（`47f600d`）。

角色和全部骨骼动作直接复用现有 KayKit 资源；碰撞、动画混合/事件、GPU 粒子、光照、音频和补间均使用 Godot 原生能力。没有另造渲染、物理、动画或通用技能框架。

修改入口：`scripts/fighter.gd` 管动作与受击，`scripts/feedback.gd` 管特效/声音，`scripts/sword_storm.gd` 管御剑与落星，`scripts/arena.gd` 管镜头和场景，`scripts/hud.gd` 管提示和设置。唯一场景为 `scenes/arena.tscn`。

## 本机验证

```powershell
./scripts/run.ps1 -Verify                 # 120 FPS
./scripts/run.ps1 -Verify -VerifyFps 60   # 60 FPS
```

两档实际渲染验证分别写入 `artifacts/verification-120fps.json` 和 `artifacts/verification-60fps.json`。先隔离辅助攻击检查近战，再检查普通连段、厉鬼多段事件/伤害/切换、真实输入、多目标伤害、原生曲线推进、八把剑的实例身份/离位空槽/原位返回/重复出击无克隆、流星概率分支、范围伤害和暂停/重置/死亡清理；性能采样覆盖四名守卫、飞剑与落星同时存在的场景。截图与录像在 `artifacts/`，不属于运行依赖。手柄映射与震动已接入，但尚未用实体手柄测试；最终主观手感仍需实玩调校。

素材来源与必要许可保留在 `THIRD_PARTY.md` 和 `licenses/`，不占用游戏界面。
