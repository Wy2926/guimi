# 烬庭 · Ember Yard

Godot 4.7 的 2.5D 封神题材竞技场肉鸽。当前由技能测试 demo 搭建正式核心战斗：人物神通决定打法，法宝决定攻击形态，固有属性与异常形成连锁，天命改变触发规则，组合进化改变攻击方式。

## 当前框架

- 默认人物神通为**哪吒·三头八臂**：常驻「多臂驭宝」，已获得的诛仙剑阵多一把飞剑，混天绫多连锁一个不同目标；不改变人物模型、原三式普攻或攻击范围。初始携带一级诛仙剑阵，实际三把飞剑。
- 只保留五法宝：**通天教主·诛仙剑阵、哪吒·混天绫、罗宣·照天印、赵公明·定海珠、太上老君·太极图**。
- 攻击属性只由法宝自带，原人物附魔／元素强化选卡已移除；四元素通道和八异常有明确归属。
- 首批联动包含绫带携火、跨法宝感电、诅咒死亡传播，以及束缚后飞剑直接贯穿的进化；天命支持暴击祭印。与常驻被动冲突的「击杀延长神通」已移除。
- 复用原竞技场、近战、法宝执行器、伤害、成长池和 HUD，不另建战斗框架。原斩击／裂环斩／厉鬼不再作为可领悟技能，近战保留为人物固有动作。

详细门槛、连锁限制、伤害口径和代码归属见 [玩法与架构](docs/gameplay-architecture.md)。这是核心框架首版，不是完整内容和平衡验收；本期没有冰／毒法宝或多人物选择。数值与反应是本作改编，不宣称照搬 DNF；小说题材不等同宗教教义。

## 美术与资源

遵循 [东方神话 · 通透灵韵](docs/art-direction.md)：清晰器形、通透分层、细亮边缘和定向流动。保留现有模型、`.blend` 源文件、GLB、材质、着色器、动画与特效；本期不重做角色美术。

旧「万剑归宗」对应现诛仙剑阵，旧「雷缚珠」对应现定海珠；所称八卦图对应已有太极图。内部 `swords`、`thunder_orb`、`taiji_aura` ID 和资产路径继续复用，避免生成重复资源。哪吒神通采用《封神演义》的题材转译法宝加成，不制作实体三头八臂或替换当前角色模型。

八种异常已补两层持续粒子及对应的控制／咒印轮廓；携火、感电传导、诅咒传播、碎冰、贯阵与天命祭印接入专用分层反馈。飞剑增加两层飞行粒子，仍复用原剑与拖尾；混天绫携火沿同一条真实绫带路径。状态刷新复用实例，反应特效限量并随暂停、死亡／结束和重开清理。具体覆盖、粒子预算与验证边界见 [特效覆盖与建模核对](docs/gameplay-architecture.md#特效覆盖与-blender-mcp-建模核对)。本轮没有新增模型，也没有必须新增的 Blender 建模项；无窗口验证不等同画面验收。

## 运行与验证

手动游玩可双击 `Play.cmd`，或用 Godot 导入 `project.godot`。自动化使用 `./scripts/run.ps1 -Verify`，默认附带 `--headless`，报告写入忽略目录 `artifacts/`。

全法宝厚血怪试炼：`./scripts/run.ps1 -CombatDemo`。五法宝全部满级，现有天命与进化解锁；哪吒仍只提供驭宝被动，不改人物模型与普攻。开局40只真实 AI 怪物，每只2万血，每2秒再生成4只，沿用80只同屏上限，击杀后继续补充；玩家10万血，怪物不掉经验，不弹升级选择，也没有十分钟终局。WASD／方向键移动、自动攻击、Esc 暂停；暂停菜单重开后仍保留试炼配置。普通 `Play.cmd` 不受影响。自动检查用 `./scripts/run.ps1 -CombatDemo -Headless`，报告为 `artifacts/combat-demo-headless.json`。

无窗口验收只证明逻辑、资源加载和生命周期，不证明画面、音频、GPU 性能或完整构筑平衡。仅在明确需要手动可见实玩时启动窗口。原混天绫演示入口保留为 `./scripts/run.ps1 -HuntianDemo`，自动检查须再加 `-Headless`。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `scenes/` | 主场景、角色与原生可复用场景 |
| `scripts/` | 对局、人物、法宝、异常结算、成长与界面，以及启动脚本 |
| `data/` | 基础属性和神通／法宝／天命／进化的原生 Resource |
| `assets/` | 模型、材质、音频、字体、概念图与 Blender 源文件 |
| `shaders/` | 共用着色器；资产专用着色器随资产保存 |
| `tools/` | 现有无窗口验证和模型制作工具 |
| `docs/` | 美术规范、核心玩法与架构 |
| `licenses/` | 第三方素材许可；来源见 [THIRD_PARTY.md](THIRD_PARTY.md) |
