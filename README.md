# 烬庭 · Ember Yard

Godot 4.7 的 2.5D 小竞技场肉鸽原型。第一职业「剑豪」，自动连斩、手动主动技能、拾取经验、升级三选一、十分钟波次与最终首领。当前用于验证玩法、手感与架构，不是生产完成版。

双击 `Play.cmd`，或用 Godot 导入 `project.godot` 后按 F5。本机使用 Godot 4.7.2 / Forward+；首次进入会预热特效。其他机器可执行：

```powershell
./scripts/run.ps1 -Godot 'C:\Tools\Godot.exe'
```

## 操作

| 操作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 普通三连 | 靠近敌人自动攻击，可同时移动 | 自动 |
| 裂环斩 | K / 右键 | RB |
| 厉鬼（升级解锁） | G | B |
| 升级选择 | 点击 / 1、2、3 / 方向键与 Enter | 方向键与 A |
| 暂停、属性与设置 | Esc | Start |
| 重开（暂停或结算时） | R / 按钮 | 菜单按钮 |
| 全屏 | F11 | — |

普攻不会自动追赶敌人。裂环可在连斩中提前按下，完成当前招式后优先释放。厉鬼是有持续时间和冷却的主动技能，不再是无限开关。万剑归宗与流星分别通过升级获得，不再默认全开。

## 一局内容

- 约 60° 固定俯角正交镜头跟随人物；圆形竞技场半径 15.8，16:10 下约为一个屏幕可见地面面积的 1.9 倍。
- 四边预警出生，追击、冲锋和远程三类怪物；每分钟集结、增压、喘息，2/5/8 分钟精英，10 分钟最终首领。击败首领胜利，玩家死亡结束，不自动复活。
- 击杀掉落经验，靠近吸附；升级暂停整个战场，三选一，溢出经验保留，连续升级逐次选择。
- 保留原有三连、厉鬼五式八击、裂环、八把剑的离位/曲线追击/归位及流星预警。辅助命中不会递归触发技能。
- 物理、魔法、固定三种伤害统一结算；固定读取独立攻击、绕过双防，仍受元素、暴击、闪避影响。
- 火冰光暗攻击与抗性已接入；元素反应、局外职业养成、装备、特殊物品、宠物不在本期实现。

暂停菜单提供 60 / 120 FPS 上限（保存选择）、镜头震动和静音；上限不是实际帧率保证。物理保持 120 Hz。手柄事件映射已验证，实体手柄和最终主观手感仍需实玩。

| 内容 | 位置 |

| 基础属性、技能倍率与等级 | `data/classes/`、`data/skills/` |

玩法规则、数值起点与后续接入边界见 [设计与架构](docs/gameplay-architecture.md)。复用当前角色、武器、动画与音频占位素材；使用原生 Resource、场景、信号、AnimationPlayer、Area3D、粒子和补间，没有新建通用战斗框架。

## 验证与版本

```powershell
./scripts/run.ps1 -Verify
./scripts/run.ps1 -Verify -VerifyFps 60
```

验证驱动使用实际主场景；报告和截图写入忽略目录 `artifacts/`。纯逻辑与 headless 结果不代表渲染性能；报告区分运行模式，群怪压力只是本机短样本，不代表最低硬件或完整十分钟平衡性验收。
